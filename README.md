# FinAlly

A trading app.

## Structure

- `backend/` – API and trading logic
- `frontend/` – web user interface
- `db/` – database schema and data
- `test/` – tests
- `planning/` – project plans (see `planning/PLAN.md`)

## Setup

Copy `.env.example` to `.env` and fill in your values (leave `MASSIVE_API_KEY` empty to use the price simulator), then follow the setup steps in `backend/` and `frontend/` (to be added).
